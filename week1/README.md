The assigned readings explore what code is, its history, and variety of uses. I think code is a useful tool or a medium for creation. Code is typically a set of instructions or algorithms which can be followed and recreated. Historically, code dates back to ancient encrypted letters, written books of law, and ciphers. Later, came the telegraph and Morse code, condensing the coded messages to be smaller than their meanings. I think the passage on Turing’s machine is interesting. Turing argued the purpose of computers is for “decoding plain human language.” He built his cryptography applications of the Turing machine which were used for code breaking in World War 2. I’m curious to learn more about quantum computing in this realm. Software Studies : A Lexicon was written in 2008 and there have been many more advances in quantum computing since then. I’m curious to learn more about how as quantum computers continue to advance and cybersecurity shifts with that: how might people come to view computing in the future? I’m reading a book right now about quantum computing [Quantum Computing for Everyone by Chris Bernhardt](https://mitpress.mit.edu/9780262539531/quantum-computing-for-everyone/) and the author argues that classical computing focuses on how humans compute and quantum computing focuses on how the universe computes, emphasizing that classical computing can be simulated by quantum computers while quantum computing can not be simulated by classical ones.
