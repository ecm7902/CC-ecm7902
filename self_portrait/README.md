# Emily's Self Portrait

For my self portrait I took inspiration from one of my current favorite hobbies, needlepoint. I tried to make the camera feed's pixels look like a needlepoint tent stitch. A needlepoint canvas is set up like a grid kind of like an array of pixels. Then, I tried out some different effects with colors and animation. I decided to display them as a grid so you can see all the effects at the same time. It was interesting to think about the different ways I might be able to build this project and get a similar result.
