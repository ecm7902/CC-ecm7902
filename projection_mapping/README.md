# Projection Mapping

---

This week I played some more with projection mapping. I decided I wanted to project onto this wall art I have in my apartment. I was thinking about the DVD player screensaver that changes when the logo hits the wall. It made me think to make the design of these circles that are added each time one hits the "wall" of the rectangular art. I worked with a class to do this. I like how the projection picks up the colors of what's underneath it. The circles are using a neutral color and then you can see the color of the panels underneath it. Now I want to try to map to more complex objects. [Here is the link to my projection mapping video.](https://drive.google.com/file/d/1ybCB4-BTwyeFaIVdLmHCMydJNB7av2aG/view?usp=sharing)
